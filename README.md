# 📚 VBSPU Prep Hub

VBSPU Prep Hub is a free educational website created to help students of Veer Bahadur Singh Purvanchal University (VBSPU) prepare for placements and improve their technical skills.

The platform provides well-organized study resources, aptitude materials, and programming notes in one place, making it easier for students to access important content without searching across multiple websites.

## ✨ Features

- 📖 Aptitude preparation resources
- 💻 Programming notes (C, C++, Java, Python, JavaScript, HTML, CSS, DBMS, OS, OOPs)
- 🌳 Data Structures & Algorithms (Arrays, Strings, Stack, Queue, Trees, Graphs, Dynamic Programming)
- 📄 One-click PDF access
- 📱 Responsive design for desktop and mobile
- ⚡ Simple, fast, and user-friendly interface.
